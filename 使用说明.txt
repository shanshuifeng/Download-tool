下载工具 · 便携版
==================

双击「下载工具.exe」就能用，不需要装 Python，插到任何 Windows 10/11 电脑上都能跑。


三步下载
--------
1. 把下载链接粘进上面的框（一行一个；有多个镜像就多贴几行）
2. 点「更改」选保存位置（U 盘、桌面、D 盘都行）
3. 点「开始下载」

每点一次「开始下载」就新增一个任务，可以接着粘下一个链接再点。
任务列表里每行有自己的进度：下载中行尾是「取消」，完成后是「打开」，
失败或取消后点「移除」清掉这一行。默认同时下 2 个文件。

输入框为空时，复制到剪贴板的直链会自动填进去（同一个链接只填一次）。


想调参数
--------
点「高级设置」，展开后有八个滑杆：线程数、分片大小、慢速断开、慢速时长、
重试次数、连接超时、全局限速、并发任务；下面还有 SHA256、镜像、代理三个输入框。

代理留空＝跟随系统代理；填 direct＝强制直连；
也可以填 http://127.0.0.1:7890 或 socks5://127.0.0.1:7891。

不确定某个该设多少，点右上角「参数说明」，里面逐条写了作用和适用场景。
所有设置会自动记住，下次打开还是上次的值。


它自己会处理的事
----------------
· GitHub 链接自动补加速镜像，并发测速后按速度分配分片
· 服务器不支持分段就自动走单线程，不会卡死
· 声称支持分段却返回整个文件的，自动退化为单线程重下
· 某一片失败会换镜像重试，间隔逐次拉长（1/2/4/8 秒）
· 连接太慢（低于动态阈值并持续一段时间）会主动断开重连
· 中途取消或断网，下次重下同一个链接会接着传；服务器文件变了则重下
· 下完核对大小；填了哈希再算一遍，不符会改名成 .corrupt，不留坏文件


注意
----
· 只支持 http/https 直链，不支持 BT、磁力、网盘分享页
· 配置文件位置：
  - U 盘里 → 就在 exe 旁边，跟着盘走
  - 放在本机桌面/文档 → 在 %APPDATA%\下载工具\config.json，不弄脏桌面
  删掉它即可恢复默认设置
· 杀毒软件可能报「未知程序」——PyInstaller 单文件程序的常见误报，
  加信任即可。介意的话可以用文件夹里的 gui.pyw 源码版（需装 Python）


源码版（需 Python 3.11+）
-------------------------
命令行：
    python downloader.py "<链接>" -o "D:\保存目录" -t 16 --sha256 <哈希>

详细说明见 README.md


给脚本 / AI 用（dl.exe）
-----------------------
同一目录下的 dl.exe 是控制台版，无窗口、可被程序调用：

    dl.exe "<链接>" -o "D://保存目录" --json

输出是每行一个 JSON（progress / done / error），退出码 0=成功、
1=失败、2=参数错误、3=所有镜像不可用。完整参数见 README.md 的
「自动化接口」章节，或直接跑 dl.exe --schema 看机器可读描述。
