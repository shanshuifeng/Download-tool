下载工具 · 便携版
==================

双击「下载工具.exe」即可运行，无需安装 Python，可直接放在移动介质上使用。
支持 Windows 10 / 11。


开始下载
--------

1. 将下载链接粘贴到输入框，一行一条；多条链接视为同一文件的镜像
2. 点击「更改」选择保存位置
3. 点击「开始下载」

每次点击「开始下载」新增一个任务，可继续粘贴下一条链接再次点击。
任务列表中每行独立显示进度：下载中行尾为「取消」，完成后为「打开」，
失败或取消后为「移除」。默认同时执行 2 个任务。

输入框为空时，复制到剪贴板的直链会自动填入，同一链接只填入一次。


参数调整
--------

点击「高级设置」展开，共八个滑杆：线程数、分片大小、慢速断开、慢速时长、
重试次数、连接超时、每任务限速、并发任务；下方另有 SHA256、镜像、代理三个输入框。

每任务限速作用于单个下载任务；同时下载多个任务时，合计速率会高于设定值。

代理留空表示跟随系统代理；填写 direct 表示强制直连；
也可填写 http://127.0.0.1:7890 或 socks5://127.0.0.1:7891。

不确定某项应如何设置时，点击右上角「参数说明」，其中逐条说明作用与适用场景。
所有设置自动保存，下次启动沿用上次取值。


自动处理的情况
--------------

- GitHub 链接自动补充加速镜像，并发测速后按速度分配分片
- 服务端不支持分段时自动转为单线程，不会停滞
- 声称支持分段却返回完整文件的，退化为单线程重新下载
- 某个分片失败时切换镜像重试，重试间隔逐次延长（1/2/4/8 秒）
- 连接速度持续低于动态阈值时主动断开重连
- 中途取消或断网后，重新下载同一链接可续传；服务端文件已变更时自动重下
- 下载结束后核对文件大小；填写哈希时重新计算并比对，不符的文件改名为 .corrupt 隔离


注意事项
--------

- 仅支持 http/https 直链，不支持 BT、磁力与网盘分享页
- 经镜像（尤其是 GitHub 加速源）下载时建议填写 SHA256：镜像只保证连通，
  不保证内容未被替换。不填写亦可下载，但内容无法验证
- 目标介质为 FAT32 时单文件上限为 4GB，程序会在开始前提示；改用 exFAT/NTFS 即可
- 保存路径过长（约 240 字符以上）时程序会提前报错，请更换层级较浅的目录或缩短文件名
- 配置文件位置：
    移动介质 → 与可执行文件同目录，随介质一同移动
    本机桌面或文档 → %APPDATA%\下载工具\config.json，不写入桌面
  删除配置文件即可恢复默认设置
- 杀毒软件可能提示「未知程序」，这是 PyInstaller 单文件程序的常见误报，
  加入信任即可。如不接受该行为，可使用源码版本 src/gui.pyw（需安装 Python）


命令行与自动化
--------------

同一可执行文件带参数即进入命令行模式：

    下载工具.exe "<链接>" -o "D:/保存目录" --json

输出为每行一个 JSON 对象（progress / done / error）。退出码含义：
0 成功，1 失败，2 参数错误，3 所有镜像不可用。完整参数见 README.md 的
「自动化接口」章节，或执行 下载工具.exe --schema 查看机器可读描述。


源码版本（需 Python 3.11 及以上）
--------------------------------

    python src/gui.pyw
    python src/dl.py "<链接>" -o "D:/保存目录" -t 16 --sha256 <哈希>

详细说明见 README.md。
